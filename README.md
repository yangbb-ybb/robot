# 3D 智能聊天助手

这是一个常驻桌面窗口的聊天机器人项目，不是网页产品。

## 启动

首次安装依赖：

```bash
npm install
```

启动桌面软件：

```bash
npm start
```

## 桌面行为

- 启动后打开桌面窗口；
- 关闭窗口按钮会隐藏到系统托盘，不会退出程序；
- 双击托盘图标可以重新显示；
- 默认不置顶，可在聊天窗口右上角或托盘菜单中打开/关闭“窗口置顶”；
- 可通过托盘菜单切换“机器人悬浮模式”：隐藏聊天面板，只在屏幕角落显示 3D 机器人并保持置顶；
- macOS 悬浮模式使用透明窗口，去掉窗口背景色，只保留机器人本体；
- 置顶设置会保存，下次启动沿用上次选择；
- 托盘菜单可以显示、隐藏或退出；
- Electron 窗口内部加载本地前端，后端 API 由应用自动启动，并会等待健康检查通过后再显示窗口；
- 3D 模型、文字聊天和交互记录保留在项目中；
- 语音识别目前只预留接口，后续接入。

## 目录

- `electron/main.js`：桌面应用主进程、托盘和本地后端启动
- `public/`：窗口内的前端界面和 3D 资源
- `server/`：本地后端 API 与交互记录
- `models/`：原始 3D 模型资源
- `docs/`：产品与技术文档
